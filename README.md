# 🚀 iNSIGHTS Copilot & AI Talent Intelligence Platform

> **Search Less. Solve More. From Idea to Execution.**
> A unified Web & Mobile Suite bringing together AI-Powered Student Research & Innovation Copilot (`iNSIGHTS Layer 2`) and the `AI Talent Intelligence & Recruitment Ecosystem`.

---

## 📸 Platform Overview

The platform features a dual-experience architecture:
1. **Desktop Web Application**: Full-blown widescreen dashboard for deep research synthesis, system architecture generation, knowledge clustering graphs, AI talent score analytics, recruiter natural language search, PPT pitch deck analysis, and pitch deck generation.
2. **Companion Mobile App Simulator**: Interactive iOS 16 Pro / Android Pixel 9 mobile app preview featuring instant idea intake, WhatsApp/Telegram agent notifications, verified digital talent pass QR, and live mobile voice interview assessments.
3. **Dual View Mode**: Side-by-side view with live real-time state synchronization between Web App and Mobile App.

---

## 🔥 Key Capabilities & Modules

### 1. 🔍 DeepSearch & Validation Engine (`iNSIGHTS Layer 2`)
- Multi-source search across arXiv papers, IEEE Xplore, Kaggle Datasets, and GitHub Repositories.
- Reliability scoring flagging outdated or weak sources.
- Automated feasibility (92%+), innovation, and impact score calculation.

### 2. 🏗️ Project HUB & Auto Architecture Generator
- Auto-generates microservice architecture diagrams (YOLOv8 CV engine, Prophet forecast model, FastAPI central orchestrator, PostgreSQL/Redis, WhatsApp API).
- Tech stack recommendations and step-by-step 4-phase milestone roadmaps.
- Recommended open-source GitHub starter repositories and Kaggle datasets.

### 3. 🕸️ Knowledge Clustering & Interactive Graph
- Groups related research findings and eliminates duplicate search results.
- Surfaces genuine innovation gaps instead of simple link lists.

### 4. 🤖 AI Agent Workforce
- Multi-agent collaboration featuring **Research Agent**, **Architecture Agent**, **Code Copilot Agent**, and **WhatsApp/Telegram Bot Agent**.
- Automated daily reminders, code boilerplate generation, and project progress tracking.

### 5. 🎯 AI Talent Intelligence & Recruitment Ecosystem
- **AI Talent Profile Engine & Talent Score™**: Generates verified candidate scores based on Coding Ability (98/100), Project Quality (95/100), Leadership (92/100), Problem Solving (94/100), and Technical Consistency (96/100).
- **Recruiter AI Copilot**: Natural language query search (*e.g., "Find top AI developers from Delhi with hackathon experience"*).
- **AI Skill Verification Engine & Interview Agent**: Live interactive technical interview evaluator with automated ratings.
- **AI PPT & Pitch Deck Analyzer**: Upload presentation pitch decks for automated technical depth scoring, innovation scoring, and 0% AI plagiarism audit.
- **Hackathon-to-Hiring Pipeline**: Direct recruitment from hackathon leaderboards based on verified GitHub code commits.
- **Trust & Fraud Prevention System**: Cryptographic certificate verification and AST code clone detection.

### 6. 📱 Interactive Companion Mobile App
- Native iOS & Android smartphone shell.
- 5 screens: **Home**, **DeepSearch Intake**, **WhatsApp Agent Chat**, **Digital Talent Pass QR**, and **Voice Audio Interview Simulator**.

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Build Tool**: Vite 5
- **Architecture**: Responsive Glassmorphic UI with CSS micro-animations
- **AI Layer**: Multi-Agent LLM Orchestration & Layer 2 DeepSearch Synthesizer
- **Backend Spec**: FastAPI / Python Microservices (PyTorch + YOLOv8 + Prophet)
- **Database Spec**: PostgreSQL + Redis Pub/Sub Queue
